# Thư mục chứa Font chữ Arcade & FGC Wiki

Vui lòng đặt các file font vào thư mục này:
1. `SVN-Determination.otf` (hoặc `.ttf`) - Dùng cho Tiêu đề, đề mục, nút bấm Arcade
2. `SVN-Coder's-Crux.ttf` - Dùng cho thông tin, số liệu, bảng Frame Data

Hệ thống đã cấu hình sẵn `@font-face` tự động nạp từ thư mục `/fonts/` này hoặc từ hệ điều hành nếu máy bạn đã cài sẵn font.
